# Media Ideya — контент внутренних страниц

Контент четырёх внутренних страниц управляется через стандартные записи DLE и дополнительные поля. HTML-структура, декоративные изображения, нумерация и motion-слои остаются в шаблоне, поэтому редактор не может случайно сломать вёрстку.

## Первичная настройка

Скрипт работает только из CLI. Без флага он выполняет безопасную проверку и ничего не меняет:

```bash
/Applications/MAMP/bin/php/php8.3.30/bin/php scripts/mi-p4-pages-content.php
```

После успешного dry-run:

```bash
/Applications/MAMP/bin/php/php8.3.30/bin/php scripts/mi-p4-pages-content.php --apply
```

P4 добавляет поля без удаления существующих, создаёт недостающие записи и сохраняет загруженные исходники в `uploads/posts/media-ideya/`. Повторный запуск не перезаписывает уже отредактированный контент.

## Где редактировать

| Страница | Раздел в DLE | Что редактируется |
|---|---|---|
| О компании | Категория **О компании (текст)**, запись `about-text` | Hero, вводный текст команды, этапы, заголовки секций и CTA |
| О компании — команда | Категория **О компании — команда** | Заголовок записи = роль, краткое описание = текст, xfield = изображение |
| О компании — отзывы | Категория **О компании — отзывы** | Текст отзыва, автор, должность, компания, фото/логотип |
| О компании — благодарности | Категория **О компании — благодарности** | Название и изображение документа |
| Услуги / Product-placement | Категория **Услуги (главная)**, запись `service-product-placement` | Hero и все смысловые блоки detail-страницы |
| Кейсы | Категория **Кейсы** | Заголовок, бренд, cover, шаги, результаты и CTA каждого кейса |
| Контакты | Категория **Контакты**, запись `site-contacts` | Телефон, email, адрес, карта, соцсети и вводный текст формы |

Статические записи `o-kompanii` и `uslugi` отвечают за URL и SEO-мета. Видимый контент этих страниц берётся из записей выше.
После P4 маршруты этих двух записей используют `static-about.tpl` и `static-services.tpl`, поэтому uncached-запросы второй страницы не выполняются.

## Важные ограничения

- Порядок команды, отзывов и благодарностей задаётся датой публикации: старые записи идут первыми.
- Для motion-секций количество слотов фиксировано дизайном: 5 hero-слов, 6 этапов About, 3 принципа, 4 формата, 6 преимуществ и 3 метрики услуги, 6 шагов и 5 результатов кейса.
- Контентные изображения загружаются через соответствующие image xfields. Облака, венки, колонны, статуи, руки и другие декоративные слои остаются частью темы.
- Ссылки Telegram и WhatsApp редактируются в полях контактов и используются в контактной странице и footer-ссылках; третья декоративная окружность сохраняет геометрию Figma без выдуманного URL.
- Форматные подписи, кнопки, labels, placeholders, CAPTCHA и consent-тексты являются интерфейсом, а не редакционным контентом.
- После установки P4 не запускайте старые P0/P1 bootstrap-скрипты: они относятся к первичной установке. Встроенная защита остановит их, если P4 уже применён.
- Hosting/deploy остаётся отключённым; P4 применяется локально и позднее отдельно на целевом окружении.

## Проверка после редактирования

Откройте:

- `/o-kompanii.html`
- `/uslugi.html`
- `/keysy/`
- `/index.php?do=feedback`

Если DLE cache включён, очистите его в админке после изменения записей.
